## 🎰 Wheel of Fortune

[Play Here!](https://codenamex0.github.io/Roulette/)

wheelofnames.com과 유사한 기능을 가진 인터랙티브 룰렛 게임입니다.

## ✨ 주요 기능

- **동적 항목 관리**: 텍스트 입력으로 항목 추가/삭제
- **항목 순서 변경**: 위/아래 화살표로 순서 조정
- **결과 모달**: 당첨 결과를 모달로 표시
- **당첨 항목 삭제**: 당첨된 항목을 바로 제거 가능
- **반응형 디자인**: 모바일/데스크탑 모두 지원

## 🚀 사용 방법

1. 왼쪽 패널에서 항목을 추가/관리
2. "Spin" 버튼을 클릭하여 룰렛 회전
3. 결과 모달에서 당첨 항목 확인
4. 필요시 당첨된 항목을 삭제하여 중복 당첨 방지

## 🛠️ 기술 스택

- **HTML5 Canvas**: 룰렛 애니메이션
- **Vanilla JavaScript**: 순수 자바스크립트로 구현
- **CSS3**: 현대적인 UI/UX 디자인
- **Pretendard 폰트**: 깔끔한 한글 폰트
